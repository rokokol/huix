Мой Wayland-десктоп на Hyprland: тайлинг `dwindle`, обвязка из waybar, mako, hypridle и обоев, бинды под vim-клавиши, скриншоты с OCR, перевод и словарь прямо из rofi, живая лупа, полноэкранные шейдеры и переключение темы на лету. На ноутбуке-трансформере к этому добавляются тачскрин, поворот экрана и режим планшета

## Как это собрано

Hyprland берётся из main-ветки его флейка, потому что конфиг на Lua есть только там. Конфиг гибридный: общий для обоих хостов `hyprland.lua` правится руками и применяется по `hyprctl reload` без ребилда, а из Nix приходит только то, что различается по хостам или берётся из палитры. `hyprland.nix` объявляет опции `rokokol.hyprland.*` и подключает `services/` — по файлу на компонент, от [waybar](services/waybar/README.md) до режима планшета

## Стек компонентов

Где выбор неочевиден:

- **`awww`** вместо `hyprpaper` — обои; на ПК картинка собирается коллажем
- **`mako`** вместо `dunst`/`swaync` — минималистичные уведомления
- **`rofi`** — моя любимая программа: лаунчер, буфер обмена, эмодзи, [словарь](https://github.com/rokokol/rofi-wooordhunt), перевод, пикер шейдеров, меню питания
- **`tesseract`** — копирование текста с экрана, по-русски и по-английски
- **`swayosd`** — экранные индикаторы громкости, яркости и раскладки

## Хоткеи

Мод — `SUPER`, "скриншотный" мод — `SUPER ALT`

| Бинд                    | Действие                                                       |
| ----------------------- | -------------------------------------------------------------- |
| `SUPER + Q`             | терминал (kitty)                                               |
| `SUPER + W`             | лаунчер (rofi)                                                 |
| `SUPER + E`             | файловый менеджер (thunar)                                     |
| `SUPER + C`             | закрыть окно                                                   |
| `SUPER + V`             | плавающее окно                                                 |
| `SUPER + F`             | фулскрин, `SUPER + P` — pseudo, `SUPER + T` — сменить сплит    |
| `SUPER + H/J/K/L`       | фокус ←↓↑→ (и стрелки)                                         |
| `SUPER SHIFT + H/J/K/L` | двигать окно ←↓↑→                                              |
| `SUPER CTRL + H/J/K/L`  | точно сдвинуть плавающее окно                                  |
| `SUPER ALT + H/J/K/L`   | изменить размер окна                                           |
| `SUPER + ЛКМ/ПКМ`       | перетащить / изменить размер окна мышью                        |

## Ноутбук-трансформер

Когда ноутбук складывается в планшет, экран сам поворачивается по акселерометру, у окон появляются заголовки с кнопками "закрыть" и "развернуть", курсор прячется, а в баре появляется кнопка экранной клавиатуры. Когда ноутбук раскладывается, всё возвращается

Жесты на тачскрине дают [hyprgrass](https://github.com/horriblename/hyprgrass) и сам Hyprland:

| Жест                         | Действие                                  |
| ---------------------------- | ----------------------------------------- |
| три пальца влево/вправо      | соседний воркспейс                        |
| небольшой свайп от бокового края | соседний воркспейс, тянется за пальцем |
| вдоль левого края            | яркость, вверх — ярче                     |
| вдоль правого края           | громкость, вверх — громче                 |
| щипок тремя                  | живая лупа                                |
| долгое нажатие тремя         | изменить размер окна                      |
| свайп от нижнего края        | меню приложений                           |
| свайп от верхнего края       | войти в фулскрин и выйти из него          |

Окно перетаскивается пальцем за заголовок и ложится на ту сторону соседнего окна, куда его бросили. В rofi и kitty палец работает как мышь: тап — клик, движение — прокрутка, а в kitty подержанный и потом ведомый палец выделяет текст. Сейчас для этого rofi собирается из ветки разработки, а kitty пропатчен — почему и до каких пор, в [WORKAROUNDS.md](../../../WORKAROUNDS.md)

## Фиксы и тонкости

- **Unreal Editor** — его невидимые окна перетаскивания не угоняют фокус
- **XWayland** — перетаскивание работает, а приложения не мылятся на дробном масштабе
- **максимизация** — запросы приложений развернуться на весь экран игнорируются
- **файловые диалоги** — открываются плавающими окнами, в том числе у xarchiver
- **блокировка** — если экран блокировки упал, сессию можно заблокировать заново, а не спасаться через tty
- **планшет Gaomon S630** — на ПК привязан к одному монитору
- **swayimg** — клавиши работают и на латинице, и на кириллице
- **крышка ноутбука** — режим "крышка только гасит экран" действует до конца сессии и после перезагрузки выключен
- **вынесенные флейки** — [шейдеры и программная яркость](https://github.com/rokokol/hyprland-screen-shader), [словарь](https://github.com/rokokol/rofi-wooordhunt) и [экран блокировки](https://github.com/rokokol/ddlc-hyprlock) живут в своих репозиториях, здесь только их подключение
