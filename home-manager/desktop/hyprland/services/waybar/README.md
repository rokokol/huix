Waybar — панель с самым нужным под рукой: рабочие пространства, нагрузка, сеть, звук, уведомления и экранные эффекты. На ПК она показывает состояние видеокарты, а на ноутбуке — батарею, подсветку и режим планшета

Многие индикаторы не просто для красоты: нажатием можно открыть лаунчер, уведомления или настройки эффектов. Сама панель подхватывает текущую тему
