Yazi is my main file manager: I open folders and archives in it, search the files by name or by content, and read the documents and the media

An archive can be changed, not only read, and the renaming and the work with Git have actions of their own. It takes the calls of other applications too, such as "show in folder". Shift+Enter opens the "open with" menu: first the applications for this kind of file, and every one of them under Ctrl+Tab

Files copy through the shared clipboard, and the look follows the light or the dark theme by itself
