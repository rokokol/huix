# Pi

[![huix](https://img.shields.io/badge/huix-наверх-222222?style=flat)](../../README.md)

Настройки pi, расширения и определения агентов собраны здесь. Скиллы и MCP приходят из общего реестра; `/modules` показывает их деревом и позволяет менять группы и отдельные ресурсы

Доступные модели OpenRouter и разрешённые хостеры задаёт общий с Hermes файл [ai-models.nix](../../../../lib/ai-models.nix). Список чат-моделей ограничивает меню моделей, а `/hoster` выбирает маршрут внутри разрешённого набора. Настройки приватности действуют независимо от выбора хостера

Настройки интерфейса остаются изменяемыми, ключи и вход в Codex не попадают в Nix store. Системная часть, которая объявляет секрет, находится в [модуле pi](../../../../nixos/services/ai/pi/README.md)

## Ресурсы и память

В `/modules` папка группы содержит скиллы и MCP-серверы, сервер раскрывается до отдельных инструментов. После разделителя находятся ресурсы вне групп. Просмотр ничего не перезагружает; изменения применяются вместе через Enter, Esc отменяет их. Справка в окне показывает переключение доступности, способа объявления инструментов и режимов памяти

Рядом с ресурсами показана приблизительная начальная стоимость контекста, а у выключенных — возможный вклад после включения. Это оценка описаний и известных схем, не счёт провайдера и не размер всей сессии; неизвестные схемы отмечены вопросом. Выключение не удаляет уже загруженный текст из истории. Изменения могут повлиять на кэш префикса, о чём pi предупреждает перед применением

Для MCP из расширений изменения применяются без полной перезагрузки сессии. Смена групп, скиллов и файловой конфигурации MCP требует reload; при работающих субагентах он запрещён, поскольку остановил бы их. Настройки MCP, которыми управляет Nix, меняются в декларативном источнике, а не перезаписываются через меню

Общая с Hermes [память Hindsight](../../../../nixos/services/ai/hindsight/README.md) доступна через MCP. Режим normal открывает обычные операции памяти, read оставляет поиск. Это выбор доступных инструментов клиента, не отдельное серверное право доступа; скрытые операции по-прежнему доступны обладателю API-токена вне этого клиента

## Общая папка и локальное состояние

[shared.nix](shared.nix) подключает изменяемые общие инструкции, собственных агентов и промпты из папки pi-shared. При переносе различающиеся локальная и общая копии `AGENTS.md` требуют ручного объединения: активация не заменяет ни одну из них

Синхронизация общей папки пропускает только инструкции, агентов, промпты и выбранные пользовательские предпочтения. Аутентификация, сессии, локальный выбор ресурсов и хостеров, сгенерированная конфигурация, кэши и журналы между рабочими хостами не смешиваются. [backup.nix](backup.nix) задаёт отдельную копию безопасной части локального состояния каждого хоста

Правила разрешений, модель классификатора и логирование единственного фильтра Auto Mode находятся в [automode.nix](automode.nix)

## Видимый план работы

Модель ведёт чеклист текущей работы инструментом `todo`: создаёт этапы, отмечает выполняемый пункт и завершает его после проверки результата. Виджет над полем ввода показывает прогресс, `/todos` — весь список. Состояние восстанавливается из ветки сессии после reload и продолжения разговора; это не отдельная база задач и не подтверждение успешности работы без проверки

Постоянные личные задачи остаются в Super Productivity. Чеклист pi автоматически туда не переносится

## Сообщения во время работы

Enter отправляет уточнение на ближайшую границу выполнения, Alt+Enter ставит сообщение после текущей работы, Esc прерывает её. Alt+↑ возвращает ожидающие сообщения в редактор. Shift+Enter или Ctrl+J вставляет новую строку; `/hotkeys` показывает действующие привязки

Субагенты могут работать в фоне и сообщать результат основной сессии. Ctrl+B переводит выполняющийся foreground-субагент в фон; отдельного плагина для этого не нужно. В tmux сочетание сначала нужно передать сквозь его префикс

## Расширения

Сторонние расширения перечислены с закреплёнными версиями в [манифесте](extensions/package.json), зависимости — в соседнем lock-файле

| Расширение | Назначение |
| --- | --- |
| `@czottmann/pi-automode` | Проверка действий по правилам разрешений отдельной моделью |
| `@juicesharp/rpiv-todo` | Чеклист текущей работы модели и живой прогресс над полем ввода; `/todos` показывает полный список |
| `@tintinweb/pi-subagents` | Самостоятельные фоновые субагенты, наблюдение и управление через `/agents` |
| `pi-bg-bash` | Фоновые shell-команды, перенос выполняющейся команды через Ctrl+Shift+B, вывод и управление через `/bg` |
| `pi-intercom` | Обмен сообщениями между сессиями |
| `@narumitw/pi-btw` | Боковой вопрос без прерывания основной работы |
| `@narumitw/pi-goal` | Продолжение работы над целью на текущей модели сессии |
| `@narumitw/pi-usage` | Отображение доступной статистики квоты провайдера |
| `@nicknisi/pi-heads-up` | Фоновые замечания о ходе работы |
| `@mrclrchtr/supi-ask-user` | Вопросы с вариантами, предпросмотром и множественным выбором |
| `@mrclrchtr/supi-cache` | Управление кэшем контекста |
| `pi-editor-selection` | Выделение и редактирование текста в поле ввода |
| `pi-multi-pass` | Несколько моделей для анализа и проверки задачи |

Фоновая команда проходит тот же фильтр разрешений, что и обычная. Модель может сама вызвать `bash` с `background: true`; делегированием занимается только расширение субагентов

## Собственные расширения

- [hoster.ts](hoster.ts) ограничивает каталог OpenRouter настроенными моделями, проверяет политику приватности и сохраняет выбор разрешённого хостера через `/hoster`
- [modules.ts](modules.ts) управляет деревом ресурсов через штатное расширение MCP pi, сохраняя пользовательские фильтры и защищая обязательные расширения
- [memory.ts](memory.ts) подключает общую память с отдельным API-токеном, не помещая его в сгенерированную конфигурацию
