# Скрипты

[![huix](https://img.shields.io/badge/huix-наверх-222222?style=for-the-badge&logo=nixos&logoColor=white)](../README.md)

Рукописные bash-скрипты, которые запускаются прямо из живого чекаута, а не из store: правка применяется сразу, без `nixos-rebuild`, и скрипт можно допиливать по ходу дела, дёргая его тем же биндом. Nix держит только их зависимости. Зовут их бинды в [`hyprland.lua`](../home-manager/desktop/hyprland/README.md#хоткеи), systemd-юниты и обёртки из [программ](../home-manager/programs/README.md). Что делает конкретный скрипт и как его звать — его `--help`

Общий код лежит в `lib/`, а `tests/run.sh` проверяет скрипты, которые говорят с компоситором, без самого компоситора; эти же тесты гоняет `nix flake check`

## Синхронизация

- **`sync.sh` сам только перематывает вперёд** — при входе в сессию и после каждого ребилда. Историю пишет и публикует только `syssync`: он коммитит всё, что есть в дереве, и пушит
- **Заодно подтягиваются `~/Projects` и общие скиллы Клода**: репозиторий без своих коммитов перематывается, со своими — ребейзится поверх upstream, а конфликтный ребейз откатывается целиком. Коммитов и пушей этот обход не делает. Репозиторий исключается файлом `nosync` внутри его `.git/`, весь обход — флагом `--no-projects`
- **`git-hooks/`** — хуки git этого репозитория: `prepare-commit-msg` ставит имя хоста в начало сообщения коммита, `commit-msg` не пропускает сообщение без текста

Пути не хардкодятся: в скриптах это `$HUIX`, в Nix — `huixDir`. Состояние, которое должно пережить перезагрузку, например тема или шейдер, лежит в `~/.local/state/huix/`
