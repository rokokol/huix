HOW IT STARTED

From frustration
to declarative

This was not love at first boot

01 / THE NAME

A small experiment

I tried NixOS and did not like it at first. I got angry and named the repository "huix", after a Russian swear word

02 / THE IDEA

One place to describe it

The idea of a declarative system drew me in. Packages, settings and services could live together in one directory, while the system stayed clean

03 / THE SYSTEM

I decided to stay

I grew comfortable with NixOS and made it my main system. The separate PC and laptop configurations became a modular flake

04 / THE STATION

A new home for Mya

Later I added a small home station and set up an isolated AI agent there. I also built a private NixOS mail server

❄

WHY NIX?

Describe it once.
Make it yours.

I like a system I can understand and change from one place. Nix lets my configuration describe the system instead of leaving its state scattered across machines

FOR PEOPLE AND AGENTS

A guide to
the system

This site began while I was building an MCP server for my agents. They need to understand how my systems fit together before they change them

The same documentation gives them an offline search and gives people a place to explore huix
