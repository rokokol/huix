Системные сервисы, разложенные по категориям `ai/`, `desktop/`, `devices/`, `system/`, `tools/`, `utils/`. Каждый сервис — отдельный модуль, а `default.nix` подключает их все на каждом хосте

Общие сервисы включены всегда, а те, что нужны только одному хосту, включаются флагом `rokokol.<имя>.enable` в `configuration-<host>.nix`. Добавить или убрать сервис с хоста — значит переключить флаг там, а не править модуль. Сервисы рабочего стола по умолчанию следуют за `rokokol.workstation.enable`, поэтому на станцию без графики они не попадают

## Сеть

Сервисы слушают только `127.0.0.1`, и firewall для них закрыт. Исключения — приёмник restic и Syncthing на станции и экспортёры метрик на каждом хосте: они слушают все интерфейсы, тайлнет до них доходит, а локалку отсекает firewall. Веб-сервис попадает в тайлнет через `rokokol.tailnet-web.sites`: nginx слушает свой порт на сайт и пускает только адреса тайлнета, а сам сервис остаётся на `127.0.0.1`. Сайт с `lan = true` открыт ещё и домашней сети, на случай если тайлнет лёг; это только для сервисов со своим входом по паролю. Порт каждого объявлен один раз в его модуле и доступен скриптам как переменная окружения. Снаружи хост доступен только через Tailscale. Shell между машинами даёт Tailscale SSH без ключей, а кто из нод куда может ходить и под каким пользователем входить, решает политика тайлнета, а не huix

## Сервисы

- **ИИ и инструменты** — Ollama, SearxNG, LibreTranslate. LibreTranslate работает офлайн на локальных моделях и обновляет их сам раз в неделю, когда есть сеть. ComfyUI, Open WebUI и Jupyter ставятся докером: их пакеты в nixpkgs тянут несогласованный CUDA-стек и долгие пересборки
- **Tailscale** — хост заводится в тайлнет вручную один раз (`sudo tailscale up`) и дальше живёт без ключей в конфиге
- **VPN** — [skvpn](https://github.com/rokokol/skvpn), переключение профилей без sudo (`skvpn up <профиль>`), российские сайты идут мимо туннеля
- **Диски** — `smartd` проверяет все диски по расписанию, короткими и длинными тестами, пропущенный тест догоняет после пробуждения, а о проблеме сообщает уведомлением на рабочий стол или, на станции, письмом
- **Метрики** — каждый хост отдаёт по тайлнету свои метрики: CPU, память, swap, диски, сеть и датчики. Экспортёр лежит в модуле того, что меряет, и включается вместе с ним: SMART там, где smartd, реальная память zram там, где zram, GPU на ПК. Prometheus на станции сам выводит из конфигураций хостов, кого и на каком порту опрашивать, опрашивает раз в 30 секунд и хранит историю год (`rokokol.prometheus.retention`). Выключенный хост на графике даёт разрыв. Чтобы временно отключить экспортёр на хосте, хватит `sudo systemctl stop prometheus-node-exporter`
- **Grafana** (станция) — графики Prometheus на порту 3200, с тайлнета и из домашней сети. Смотреть может кто угодно без входа, менять — только `admin` с паролем из `secrets/station.yaml`, из любой из двух сетей. Пароль ставится только при первом запуске: чтобы сменить его потом, сначала `grafana cli admin reset-admin-password`, затем секрет. Плагины приходят из nixpkgs, и сама Grafana ничего не скачивает
- **Бэкапы** (станция) — приёмник restic в режиме append-only: каждая машина пишет в свой репозиторий по тайлнету и не может ни удалить, ни переписать старые снапшоты. Ключа от репозиториев станция не знает. Сторож регулярно проверяет, что ни одна машина не пропала и место на томе не кончается
- **Forgejo** (станция) — свой git-хостинг по HTTP, с тайлнета и из домашней сети. Регистрации нет, есть один аккаунт владельца: при первом запуске он создаётся со случайным паролем, который лежит в `/var/lib/forgejo/initial-admin-password` и меняется при первом входе. Каждую ночь делается dump. Задачи CI ждут выключенный ПК неделю. Раз в сутки появляются зеркала всех репозиториев с GitHub, кроме форков, плюс форки из списка и минус исключённые; приватные остаются приватными, а после смены токена GitHub пересоздаются сами. Зеркало, чей репозиторий исчез с GitHub, остаётся
- **CI** (ПК) — раннер Forgejo Actions выполняет задачи станции по одной, каждую в контейнере Docker без сокета Docker, без привилегий и без томов хоста, с пониженным приоритетом CPU. Пока ПК выключен, задачи ждут его неделю. Секрет раннера один и лежит в `secrets/station.yaml`: станция регистрирует по нему раннер, ПК по нему подключается
- **Алерты почтой** (станция) — у хоста без рабочего стола уведомлениям некуда приходить, поэтому сбой важного юнита уходит письмом через SMTP-релей
- **Датчики** (ноутбук) — акселерометр для автоповорота экрана в режиме планшета. После первого включения нужна перезагрузка, а не перелогин
- **Syncthing** — синхронизация волта заметок и общего состояния Claude Code между рабочими машинами и телефоном. Станция держит архив обеих папок в `/srv/backup/syncthing`: она только принимает изменения и хранит то, что удалили или перезаписали на любом устройстве, в `.stversions` рядом с папкой — волт 90 дней, Claude Code 30 дней (`keepDays` в модуле). Версии есть только на станции и никуда не синхронизируются. Достать старую версию: `scp nixos-station:/srv/backup/syncthing/myWiki/.stversions/<путь>~<дата>.md .`. Каждый хост сам задаёт свой ID в `rokokol.syncthing.deviceId`, и остальные хосты берут его оттуда, а телефон настраивается со своей стороны, и станцию на нём один раз принимают руками
